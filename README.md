# Command-Line Expense Tracker

A simple yet robust command-line application to track personal expenses, built in Python as part of a project-based learning approach to strengthen core programming concepts.

## Features
- Add new expenses with amount, category, and description
- View all recorded expenses
- Delete expenses by entry
- Calculate total spending by category
- Persistent data storage using JSON (data is saved and loaded automatically)
- Menu-driven interface for easy navigation

## Concepts Used
- Object-Oriented Programming (`Expense` and `ExpenseTracker` classes)
- File Handling (reading/writing JSON)
- Exception Handling (input validation and error handling)

## How to Run
```bash
python expense_tracker.py
```

## Tech Stack
- Python 3
- JSON (for data persistence)
